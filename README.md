# AskFree

**Ask without fear.** AskFree is an anonymous doubt-solving platform for first-year engineering students, built to turn silent doubts into solved ones before they become backlogs.

## The Problem

In large first-year classes, many students never ask their doubts. Some fear being judged, some struggle to phrase the question, and others are not comfortable in the language of instruction. Unasked doubts pile up into backlogs, and backlogs turn into failed exams. In a survey of 27 first-year students, 26 reported having doubts in class, 12 said they rarely or never ask them, and fear of judgment was the most common reason.

## The Solution

AskFree lets students post doubts anonymously, tagged by subject and topic. Because posts are anonymous, students can ask the questions they would never raise in class. Each doubt is designed to receive:

1. **An instant AI explanation** in English, Hindi or a regional language (planned)
2. **A verified senior mentor's answer**, marked with a badge
3. **A "still confused?" option** that signals which doubts need a simpler explanation

A **weak-topic tracker** shows each student which topics to revise first.

## How It Is Different

- ChatGPT has no peer layer or syllabus context.
- WhatsApp groups lack anonymity and bury answers.
- Doubtnut targets school exams, not first-year engineering.
- AskFree combines anonymity, AI and seniors.

## Current Status

This is a working MVP in progress. The current version supports anonymous sign-in, posting doubts by subject and topic, a live shared feed, "still confused" signals, a senior mentor answer mode and a personal weak-topic tracker. AI explanations in multiple languages are the next milestone.

## Tech Stack

- HTML, CSS and JavaScript front end (React migration planned)
- Firebase Authentication (anonymous sign-in)
- Cloud Firestore for real-time data
- GitHub Pages for hosting
- LLM API for AI explanations (planned)

## Pilot Plan

The pilot will run with my batch and senior volunteers. Success will be measured by how many doubts get solved, how quickly they get answered, and how students rate the answers. The design scales to other branches and colleges through syllabus tags.
